# 🌙 Mohammad Hazi Moinuddin Basha - Biodata Portfolio Website

An animated, responsive, luxury **Islamic Emerald & Royal Gold** Matrimonial & Academic Portfolio website for **Mohammad Hazi Moinuddin Basha** (Assistant Professor at VIT-AP University Amaravati, Ph.D. Scholar [Pursuing], M.Tech, B.Tech).

## ✨ Features
- **Royal Islamic Aesthetic**: Emerald green & metallic gold theme with Arabic calligraphy banner *"بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ"*, swaying Islamic lanterns (Fanoos), and Quranic marriage blessings from Surah Al-Furqan (25:74).
- **Interactive Starlight Canvas**: Real-time golden particle physics animation responding subtly to mouse interaction.
- **Photo Gallery**: Showcasing personal and academic portraits (`photo_formal.jpg` and `photo_beach.jpg`) with 3D tilt effects and fullscreen zoomable lightbox.
- **Dedicated Download Options**: Direct high-resolution download of the official matrimonial biodata poster (`biodata_card.jpg`), print-to-PDF engine (`window.print()`), and modal preview on demand.
- **Academic Qualifications**: B.Tech., M.Tech., Ph.D. [Pursuing], and Assistant Professor role at VIT-AP University.
- **Interactive Audio**: Peaceful pentatonic audio chime toggle (pure Web Audio API, zero external MP3 dependencies).
- **One-Click Sharing**: WhatsApp share link and instant clipboard copy utility.

## 🚀 Getting Started
Open `index.html` directly in any web browser (Google Chrome, Safari, Firefox, Edge). No build step or server setup required.
